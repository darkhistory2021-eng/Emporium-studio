# The Emporium Studio

A mobile-first prototype for planning scenes and assembling simple camera-movement videos.

## Run it
- For a quick test, open `index.html` in a modern desktop browser.
- For iPhone home-screen installation and offline caching, host this folder on an HTTPS static host (for example, GitHub Pages).
- In iPhone Safari, open the hosted URL, tap Share, then Add to Home Screen.

## Current features
- Episode title and notes
- Keeper reference image upload
- Scene images, descriptions, dialogue, durations and camera movement
- Local project saving and JSON backup
- Animated still-image preview
- Browser-based video recording where supported

## Limitations
This is not an AI video generator. It does not generate new character motion, speech, or lip-sync. Video export depends on browser MediaRecorder support and may produce MP4 or WebM depending on the device. Keep project backups; browser storage can be cleared by iOS.

No paid API or subscription is required for the current local editing features.
